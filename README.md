# Bitcoin Tracker (Chart1)

تطبيق ويب يعرض سعر البيتكوين بشكل مباشر مع ميزات مثل:
- إشعارات فورية عند تغيّر السعر
- رسوم بيانية لتاريخ الأسعار
- تنبيهات صوتية وبريدية
- واجهة مستخدم تفاعلية باستخدام React + Firebase

## بدء التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

## المعاينة

```bash
npm run preview
```
